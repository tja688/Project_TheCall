# 新怪物系统交接

2026-10-20 删除了整套旧怪物拼接。不要从 git 历史把这些类型接回现有画像。新系统从本文的缝开始写。

## 现在还在画的东西

`MonsterPortrait` 只显示整张剪影。图来自 `Assets/Resources/ShadowMonsterCatalog.asset`。选图种子是 `Recipe * 19349663 + Palette * 83492791`。同一只怪物在开局、宿舍、工作区、收容柜、商店、结算和拖动虚影里用同一张图。

剪影还有整体呼吸，以及结算时的小幅倾斜。拖拽仍走 `Grab`、`Hold`、`Release`。这些都不是新系统，可以整段替换。

## 规则里留下的外观

`MonsterAppearance` 只剩 `Recipe`（0–5）和 `Palette`（0–5）。

- `FromSeed` 的取模和旧版相同，已有怪物的剪影不会因这次删除改图。
- `Breed` 不再遗传部件。配方仍用原来的身体抽选，色板仍跟次代亲本。`BreedingSystem.Spawn` 还在调用它。
- 新系统若要保存部件、骨骼或遗传，改这个结构，并改 `RunModel` 构造怪物时写入的 `Appearance`。

## 建议替换的缝

正式画面都从 `MonsterPortrait.Show(MonsterAppearance)` 进来。调用点：

- `PresentationReadout`：开局、笼子、提取、培育
- `ShopScreenView`：商店
- `ResultScreenView`：胜负
- `MonsterPortrait.SpawnGhost`：拖拽虚影

结算弹动在 `ScoringShow` 和 `ScoringShow.Energy`，调用 `SetSpringMotion`。现在只把剪影倾斜几度。

画像预制体是 `Assets/Prefabs/UI/MonsterPortrait.prefab`。部件子节点已去掉，矩形仍是 279×299。槽位卡嵌的是这份预制体。

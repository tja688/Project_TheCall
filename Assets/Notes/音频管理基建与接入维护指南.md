## 文件与职责

- `Assets/Sound/GameAudioMixer.mixer`: Master > BGM、SFX，暴露 `MasterVolume`、`MusicVolume`、`SFXVolume`。项目配置表前文写 BGM、后文写 Music，此实现实际 Group 名使用 `BGM`，音量参数仍使用 `MusicVolume`。
- `Assets/Resources/GameAudioCatalog.asset`: 四首 WAV 的**序列化 AudioClip GUID 引用** + Mixer / Group 引用。不要把 WAV 重新拷贝进 Resources；此资产让 Unity 打包真实引用，并避免依赖文件名字符串。新增音乐时编辑 Catalog，而不是字符串路径。
- `Assets/Scripts/Presentation/Audio/MusicManager.cs`: 全局 `DontDestroyOnLoad` 独占两个 AudioSource，单曲循环，unscaledDeltaTime 交叉淡化；中途打断先停止较弱音轨；相同目标请求不会重播；停止时清空 clip；Unity PlayMode 静态重置及对象销毁也释放播放状态。
- `GameAudioSettings.cs`: 统一 `SetMasterVolume/SetMusicVolume/SetSfxVolume` (0..1) 和 `SetMusicEnabled/SetSfxEnabled`，PlayerPrefs 存储，音量转换为 Mixer dB；`Save()` 可由设置 UI 在关闭面板时调用。
- `GameSfx.cs`: 基于 QFramework **AudioKit.PlaySound(AudioClip)** 的一次性和归属宿主循环音效 API，`GameSfx.StopAll()` 用于返回菜单/会话重置。暂未把具体音效节点接入游戏逻辑。
- `QFramework/.../AudioPlayer.cs`: 只增一个 `OutputMixerGroup` setter（少量 vendor 改动），让 AudioKit 池化音效可真正路由至 SFX 总线；升级 AudioKit 时注意重新保留/核对该 setter。
- `TheCallPresentation.Show`：以实际显示的页面驱动 BGM，**不在 ConfirmSettlementCommand 或 RunPhase.Shop 提前播商店音乐**。
- `ScoringShow.Run`：只有实际进入 PayCue 时请求静音，工资结算演出等之前的动作不提前静音。

## QFramework 加载问题 & 使用约束

本项目 AudioKit 的默认 `DefaultAudioLoader` 使用 `Resources.Load<AudioClip>(assetName)`。四首 WAV 在 `Assets/Sound/BGM`，字符串 `AudioKit.PlayMusic("Sound/BGM/...")` 会加载失败；调用 `AudioKit.PlayMusic(clip)` 虽可绕过加载，但单个 MusicPlayer **无法同时控制旧曲和新曲交叉淡化**，且 `AudioManager.CurrentMusicName` 与音乐开关自动重播机制存在重入风险。

**约定：所有 BGM 一律交由 MusicManager，禁止业务代码直接调用 `AudioKit.PlayMusic / StopMusic / ResumeMusic`。** MusicManager 启动/会话重置时会主动停止 AudioKit 原生单音轨，以减少来源冲突。后续希望完全解除原 AudioKit 的音乐自动恢复机制，可在升级框架时新增由游戏侧关闭此行为的明确配置，不建议业务层依赖其私有状态。

音效不允许直接按非 Resources 路径 `AudioKit.PlaySound("...")`。使用 `GameSfx.PlayOneShot(AudioClip)` 或 `GameSfx.PlayLoop(GameObject owner, AudioClip)`，务必通过序列化、ScriptableObject catalog 或 Addressables 加载的 **AudioClip 对象**传参。`GameSfx.StopLoop(owner)` 手动停止；`OnDisable / OnDestroy` 自动停止宿主循环音效。非循环短音效由 AudioKit 池自回收，返回菜单、退出时调用 `GameSfx.StopAll()`，避免声音延续到下一局。循环音效资源未配齐前不要在业务层写临时 PlaySound。

## 状态安全策略

1. 只有 MusicManager 持有 BGM AudioSource，正常最多一首；交叉淡化最多两首，取消旧协程并清除多余轨道。
2. 不依赖场景名称、不用 `Invoke` 的固定秒数，不在 UI 点击之前或 Domain 逻辑提交时播放新界面音乐。
3. 同一 BGM 重复刷新不可重播；中途 A→B→C / A→静音→Menu 应无幽灵源、无滞留协程。
4. 使用 `Time.unscaledDeltaTime` 保证 Time.timeScale=0 时也能淡入淡出，暂停、设置页不会更改 BGM 所属阶段。
5. 会话重置统一硬停止 BGM 和所有 AudioKit SFX；静音没有待恢复的播放协程；游戏对象退出时清理。
6. 切换 `SetMusicEnabled(false)` 是静音当前 BGM 的 bus，而不是改变逻辑音乐状态；重新开启只恢复当前应当播放的曲目，不会偷偷恢复上一场景。
7. `GameAudioSettings` 负责 Mixer SFX dB，QFramework 的 `SoundVolume` 在 Mixer 存在时保持 1，避免 **QFramework 的音量 × Mixer 音量** 双重衰减。音效开关仍使用 AudioKit Settings.IsSoundOn。后续设置 UI 只能调用 GameAudioSettings，不要直接修改 QFramework SoundVolume。
8. 一次性音效默认沿用 AudioKit 的同时发声/限帧策略，若设计需要同类音效节流，可用 `AudioKit.PlaySoundMode` 配置（但不要更改音乐管理）。

## 给后续 AI 的最短示例

```csharp
// 用 Inspector 或 ScriptableObject 引用 AudioClip，别写路径字符串
[SerializeField] AudioClip clickSfx;
[SerializeField] AudioClip loopingMachine;

void OnClick() => GameSfx.PlayOneShot(clickSfx);
void StartWork() => GameSfx.PlayLoop(gameObject, loopingMachine);
void StopWork() => GameSfx.StopLoop(gameObject);

// 教程界面真实展示时（此分支目前还没有教程 UI）
void OnTutorialShown() => MusicManager.EnterTutorial();

// 设置页 slider 0..1
void OnMasterSlider(float v) => GameAudioSettings.SetMasterVolume(v);
void OnMusicSlider(float v) => GameAudioSettings.SetMusicVolume(v);
void OnSfxSlider(float v) => GameAudioSettings.SetSfxVolume(v);
```

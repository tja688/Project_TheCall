# 音频需求
《怪物育成公司》的 BGM 与音效需求单，覆盖音频的制作、替换与验收范围。

## 一、文档范围
本单覆盖《怪物育成公司》全部音频：6 段 BGM，以及 UI、Player、Skill、Level、Ambience 五类音效，共 54 项。

优先级：P0 为可玩性必需（缺了流程不成立），P1 为体验增强、可后补。

## 二、目录结构
运行时音频统一放在 Audio/：

```text
Audio/
├── BGM/
├── SFX/
│   ├── UI/
│   ├── Player/
│   ├── Skill/
│   ├── Level/
│   └── Ambience/
└── Source/
```

Source/ 只存放可编辑源文件，运行时目录只放最终导出文件。

## 三、命名与格式
| 项目     | 规则                             |
| ------ | ------------------------------ |
| BGM 状态 | 主菜单 / 局内日常 / 结算 / 商店 / 通关 / 失败 |
| 音效命名   | S_对象_事件_变体.wav                 |
| 变体编号   | 两位数字，从 01 开始                   |
| 循环资源   | 文件名加 Loop 标记                   |
| 循环检查   | 循环音频需检查循环点，避免明显断点或过长静音         |

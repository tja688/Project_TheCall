
| 流程       | 详细描述                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 1.开始阶段   | 确认本关卡需上交能量数额，若上一关卡培育槽满足育种条件，将新育种出的怪物加入怪物笼                                                                                       |
| 2.操作阶段   | 玩家在此阶段可按照任意顺序将怪物放入提取槽，将任意怪物放入培育槽，当玩家确定完操作后自行决定结算该阶段                                                                             |
| 3.结算阶段   | 按顺序结算怪物效果，结算怪物获得的能量                                                                                                             |
| 4.扣除阶段   | 扣除本关尚未偿付的能量目标，若剩余能量大于等于0则进入下一阶段；若能量小于0，则记录当前欠额并返回操作阶段进行一次加班操作，加班只需补足该欠额，不重新要求完整关卡目标；若加班后仍未补足欠额则游戏失败；完成扣除后，若本次产出能量达到本关超额能量，获得1点科技点 |
| 5.工资结算阶段 | 将剩余能量清零，发放40金币，若加班过则只获得20金币                                                                                                     |
| 6.商店购买阶段 | 进入商店自行选择是否购买物品，自行选择何时结束该阶段                                                                                                      |
| 7.通关阶段   | 结束当前关卡，若本关卡为最终关卡，则游戏胜利，否则进入下一关卡                                                                                                 |

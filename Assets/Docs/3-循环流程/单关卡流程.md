# 单关卡流程

| 流程       | 详细描述                                                                               |
| -------- | ---------------------------------------------------------------------------------- |
| 1.开始阶段   | 确认本关需求能量；若上一关培育槽已放入怪物（满足育种条件），将新育种出的怪物加入怪物笼；若上一关有保留的能量，则计入本关的当前能量                  |
| 2.操作阶段   | 玩家按任意顺序把怪物放入提取槽，也可把任意怪物放入培育槽；操作完毕后，自行决定何时结算该阶段                                     |
| 3.结算阶段   | 按提取槽从左到右的顺序结算怪物效果，得到本关的当前能量                                                        |
| 4.扣除阶段   | 当前能量达到本关需求能量后，则进入下一阶段，若未达到则回到操作阶段重新摆放并再结算一次，两次产出累加后再判定，仍未达到则游戏失败。（达到超额能量获得 1 点科技点） |
| 5.工资结算阶段 | 先结算「能量保留」类效果（如工具蓄热熔炉，保留剩余能量的 20% 带入下一关），再将其余能量清零；发放 60 金币，若进行了两次操作阶段则只获得 40 金币     |
| 6.商店购买阶段 | 进入商店，自行选择是否购买物品、何时结束该阶段                                                            |
| 7.通关阶段   | 结束当前关；若本关为最终关，则游戏胜利，否则进入下一关                                                        |

# 整局流程

| 流程     | 详细描述                                                                                                                    |
| ------ | ----------------------------------------------------------------------------------------------------------------------- |
| 1.游戏开始 | 从三只双技能怪物中选一只加入怪物笼（每只都是"一个增幅技能 + 一个其他任意功能类型技能"）；选择完毕后，再把八只单技能怪物加入怪物笼——其中 4 只固定属于产能类型，另外 4 只固定属于辅助类型（类型固定，具体技能随机）。开局金币为 0 |
| 2.关卡阶段 | 进入关卡，详见《单关卡流程》；不断循环此阶段，直到游戏胜利或失败                                                                                        |

# 怪物收容编号

怪物在本局内按**生成顺序**自动领取一个收容编号，用于 UI 标题与辨认。编号与所携带的技能无关；一只怪物可拥有 1～4 个技能，名称始终为下表中的编号。

编号风格参考 SCP 基金会档案：刻意跳号、混用社区熟知条目与高位编号，不是严格的 1、2、3… 顺序。

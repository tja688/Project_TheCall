# 通用规则
性格均为被动（光环被动 / 触发被动）。

性格稀有度概率：白 50% / 蓝 20% / 负面 20% / 金 10%。

| 性格名称 | 具体效果                                                     | 类型   | 稀有度 |
| ---- | -------------------------------------------------------- | ---- | --- |
| 稳定   | 心情总是处于普通                                                 | 光环被动 | 白   |
| 孤僻   | 当相邻没有其他怪物时，本怪物的**能量值**翻倍                                 | 光环被动 | 白   |
| 重视血脉 | 当子代与亲本一起在提取槽时，亲本与子代相同的技能触发次数+1                           | 光环被动 | 白   |
| 合群   | 每有一个相邻怪物，本怪物的**能量值**+1                                   | 光环被动 | 白   |
| 自私   | 相邻的其他怪物**能量值**-3，本怪物的**能量值**翻倍                           | 光环被动 | 白   |
| 独立   | 本怪物的**能量值**不会被其他怪物的技能改变（只挡其他怪物的**技能**，不挡性格与工具）           | 光环被动 | 白   |
| 恋爱脑  | 本怪物只与一个怪物相邻时，本怪物与该怪物的**能量值**+2                           | 光环被动 | 白   |
| 自律   | 结算阶段时，产生 5 点能量                                           | 触发被动 | 白   |
| 安于现状 | 本怪物拥有的技能上限为 2，每个主动技能触发次数+1                               | 光环被动 | 白   |
| 贪财   | 本怪物每触发一次主动技能就获得 1 金币                                     | 触发被动 | 白   |
| 急躁   | 当本怪物为提取槽最左侧怪物时，本怪物的**能量值**+3                             | 光环被动 | 白   |
| 稳重   | 当本怪物为提取槽最右侧怪物时，本怪物的**能量值**+3                             | 光环被动 | 白   |
| 乐天派  | 心情总是处于热情                                                 | 光环被动 | 蓝   |
| 热爱工作 | 本怪物心情不会低于普通，连续进入提取槽达到 2-3 天时心情变为热情，连续进入提取槽大于等于 4 天心情变为热爱 | 光环被动 | 蓝   |
| 乐于助人 | 相邻怪物的**能量值**+2                                           | 光环被动 | 蓝   |
| 依赖   | 本怪物的**能量值**增加或减少时，变化量翻倍（变化量来源不限，含基础产出、心情、工具）             | 光环被动 | 蓝   |
| 好学   | **开工**获得一个提取槽上随机怪物的技能，随后将性格替换为该怪物的性格（提取槽为空则不触发本性格）       | 触发被动 | 蓝   |
| 好奇   | 开始阶段时，获得一个随机技能然后将剩余技能随机成其他技能（当技能达到上限时，将不再触发）             | 触发被动 | 金   |
| 上进心  | 开始阶段时，本怪物的**能量值****永久**+1                                | 触发被动 | 金   |
| 迷恋死亡 | 基因槽内的技能可以直接安装到本怪物身上使用                                    | 光环被动 | 金   |
| 摸鱼派  | 心情总是处于疲倦                                                 | 光环被动 | 负面  |
| 厌恶工作 | 本怪物连续进入提取槽大于等于 2 天心情便会变为倦怠                               | 光环被动 | 负面  |
| 厌世   | 心情总是处于倦怠                                                 | 光环被动 | 负面  |
| 仇恨血脉 | 当子代与亲本一起在提取槽时，亲本与子代相同的技能，其**能量值**-3                      | 光环被动 | 负面  |
| 随心所欲 | 本怪物的每个主动技能有 20%几率不生效                                     | 光环被动 | 负面  |

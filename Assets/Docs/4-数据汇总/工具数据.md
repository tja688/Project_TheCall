# 通用规则
工具是提供额外帮助的道具，均为被动，每种每局最多一件，总持有量不设额外栏位上限。已购工具退出本局货架；随机抽取与具体联动边界以[已确认落地规格](../../../docs/specs/new-planning-playable-migration.md)为准。

工具稀有度概率：白 70% / 蓝 20% / 金 10%。

工具价格按稀有度的基础值为白 30 / 蓝 50 / 金 80 金币，可根据具体强度浮动。

# 通用规则
技能带来的增减默认不跨关卡保留（包括获得的技能），只有带**永久**词条的技能例外。

技能稀有度概率：白 70% / 蓝 20% / 金 10%。

增幅技能不会单独出现，一定与其他类型的技能搭配（单技能怪物不会持有增幅技能）。

标注多个功能类型的技能，同时属于这些功能类型各自的抽取池。

| ------ | ---------------------------------------------------------------------- | ---- | ----- | --- |

| 右能量体   | 左侧每有一个怪物产生 2 点能量                                                       | 主动   | 产能    | 白   |
| 双头能量体  | 产生 2 点能量两次                                                             | 主动   | 产能    | 白   |

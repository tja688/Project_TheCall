# 定义
玩家需要克服的难题


达标只看扣除能量数。产出高于该目标时显示超额。过关后剩余能量清零，并获得 1 科技点。超额能量一列不再作为科技点门槛。

| 关卡序列    | 扣除能量数 | 超额能量 |
| ------- | ----- | ---- |
| 1       | 50    | 60   |
| 2       | 75    | 90   |
| 3       | 100   | 120  |
| 4       | 150   | 175  |
| 5       | 200   | 230  |
| 6       | 250   | 285  |
| 7（最终关卡） | 300   | 350  |

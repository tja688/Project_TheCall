# 循环

## 一、关卡内循环（最小循环）

单个关卡内的完整流程，边界为「进入关卡 → 通关并进入下一关」。

| 顺序            | 规则层描述                                            |
| ------------- | ------------------------------------------------ |
| 1. **开始阶段**   | 确认本关需求能量；结算上一关培育槽产出的子代，放入怪物笼；计入上一关保留的能量          |
| 2. **操作阶段**   | 自由摆放怪物到提取槽与培育槽，摆好后自行决定何时结算                       |
| 3. **结算阶段**   | 按提取槽从左到右结算怪物效果，得到本关卡的当前能量                        |
| 4. **扣除阶段**   | 当前能量与需求能量相抵；未达到则回到操作阶段重新摆放并再结算一次（两次产出累加），仍未达到则失败 |
| 5. **工资结算阶段** | 先结算「能量保留」类效果，再将其余能量清零；发放金币（进行了两次操作阶段则只发 40）      |
| 6. **商店购买阶段** | 自行选择购买物品与何时结束该阶段                                 |
| 7. **通关阶段**   | 结束本关；若为最终关卡则通关，否则进入下一关                           |

> 详见《单关卡流程》。

## 二、养育循环（跨关卡）

在操作阶段把至少两只怪物（可附基因）放入培育槽；下一关开始阶段，新育种出的子代加入怪物笼，即可投入使用。

## 三、关卡推进

全局共 7 关，第 7 关为最终关卡，逐关推进、不可跳关；全部通过即通关，任一天未达标则整局失败。

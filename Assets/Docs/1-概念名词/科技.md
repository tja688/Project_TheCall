# 定义
消耗科技点获得的加成效果，可在操作阶段自由解锁。

# 科技点
通过超额能量获得的货币，用来解锁科技。

| 名称   | 详细效果                             | 科技点消耗 |
| ---- | -------------------------------- | ----- |
| 基因实验 | 培育槽可放入基因数量+1                     | 1     |
| 槽位扩容 | 额外获得一个培育槽                        | 1     |
| 变异学说 | 培育槽诞生的新怪物有 10%的概率从技能池中额外获得一个随机技能 | 1     |
| 大乱炖  | 培育槽可放入怪物数量+1                     | 1     |
| 科学培育 | 培育槽诞生的新怪物有 10%的概率产生的**能量值**+2    | 1     |
| 基因仓储 | 基因槽上限+1                          | 1     |

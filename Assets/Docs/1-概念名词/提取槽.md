# 定义
通过摆放怪物、从怪物身上获取能量的区域。

# 能量提取
提取槽初始有 5 个可摆放怪物的格子；玩家在操作阶段可自主选择摆放顺序，结算阶段会按顺序、依据怪物的技能效果自动产生能量。

# 结算顺序
结算顺序严格按下方表格执行。

| 优先级顺序 | 名称     | 描述                                                                                       |
| ----- | ------ | ---------------------------------------------------------------------------------------- |
| 1     | 光环被动技能 | 无触发条件的光环被动技能，在怪物处于提取槽上时一直生效                                                              |
| 2     | 触发被动技能 | 触发被动技能当其满足触发条件时立即触发；若有两个及以上的触发被动技能同时触发，则优先级按照在提取槽的位置从左到右和单卡从上到下的顺序来触发；未满足触发条件的触发被动技能不会触发 |
| 3     | 主动技能   | 主动技能的结算顺序按照从左到右依次计算，单卡有多技能则从上到下依次触发                                                      |

> 本表用于**多个类型的效果同时生效时**判定谁先结算，**不是**按此表逐层执行的流水线；同一只怪物能量值内部的先后，见 `能量.md` 的「结算次序」。

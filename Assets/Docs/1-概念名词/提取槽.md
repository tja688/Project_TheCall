# 定义
通过摆放怪物然后从怪物身上获得能量的区域

# 能量提取
提取槽初始拥有5个可摆放怪物的格子，玩家在操作阶段可自主选择怪物的摆放顺序，在结算阶段时，将根据怪物拥有的技能效果按顺序自动产生能量

# 结算顺序

结算顺序严格按照下方表格执行

| 优先级顺序 | 名称      | 描述                                                                                         |
| ----- | ------- | ------------------------------------------------------------------------------------------ |
| 1     | 光环被动技能  | 无触发条件的光环被动技能在怪物处于提取槽上时一直生效                                                                 |
| 2     | 触发式被动技能 | 触发式被动技能当其满足触发条件时立即触发，若有两个及以上的触发式被动技能同时触发，则优先级按照在提取槽的位置从左到右和单卡从上到下的顺序来触发，未满足触发条件触发式被动技能不会触发 |
| 3     | 主动技能    | 主动技能结算顺序按照从左到右依次计算，单卡有多技能则从上到下依次触发                                                         |

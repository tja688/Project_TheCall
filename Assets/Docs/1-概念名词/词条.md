# 定义
将某个大量使用的效果或量值进行具体命名，以减少描述的字量。描述中的词条以**加粗**显示，悬停可查看解释。

| 名称      | 效果                          |
| ------- | --------------------------- |
| **消灭**  | 将怪物从游戏中移除                   |
| **永久**  | 获得的增益和减益都可以跨关卡保留            |
| **不动**  | 不能与怪物交换位置                   |
| **遗赠**  | 当本怪物在提取槽从被**消灭**时           |
| **开工**  | 当怪物放置到提取槽时                  |
| **能量值** | 一次产出标注的能量点数，即"产生 X 点能量"中的 X |

# 定义
压榨怪物产生的副产物，是通关需要的计数单位。

# 能量值
**能量值**指一条"产生 X 点能量"里标注的 X。技能和性格产生的能量都用这个词称呼。

1. 改动产出量时一律写**能量值**，例如"本怪物的**能量值**+1""相邻怪物的**能量值**翻倍"，不再写"数值""产生的能量"等说法。
2. **能量值**前要写清归属：本怪物的 / 相邻怪物的 / 该技能的。
3. "其他怪物的**能量值**+1"表示对方每个产生能量的技能各自+1，不是总共+1。
4. 未明说限定“技能”或“性格”等来源的**能量值**加成，对所有符合目标描述的产能来源生效，包括技能、性格及工具；“本怪物”“相邻怪物”“全场”等目标范围仍有效。明确限定来源的效果只作用于该来源。详见[已确认落地规格](../../../docs/specs/new-planning-playable-migration.md)的“默认全来源加成”。

# 结算次序
同一次结算中，一只怪物的能量值按以下次序算出（**不按来源分层，只按行为归位**）：

1. **触发次数**：先定每个技能本回合触发几次。触发次数+1 表示该技能**完整再结算一次**；次数可叠加、无上限，并会再次触发"每触发一次"类效果。
2. **加减**：所有 +N / −N 累加；同层内按提取槽从左到右、单卡从上到下生效。工具「精神操控仪」直接给性格提供的加成每笔 +1。
3. **变化量翻倍**：「依赖」把第 2 步得到的净变化量翻倍。
4. **总量翻倍**：镜眼、自私、孤僻、急急装置、劣胜装置等，以第 3 步结果为基数翻倍；各来源互不传导，可叠乘。

基础产能不被「依赖」翻倍；基础 5、净变化 +3 时为 11。单次最终产能最低为 0，不倒扣已积累能量。

> 位置类条件（最左 / 最右 / 相邻）一律按**进入结算时**的位置判定一次，换位不回头重算；换位**之后**才发生的判定才用新位置。

# 剩余能量
本关卡的当前能量减去需求能量后的差额。

# 超额能量
本关扣除前的当前能量达到超额门槛（含相等）后，获得 1 点科技点，每关最多一次。当前能量包含上一关保留量及本关两次结算累加量。

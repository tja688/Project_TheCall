# 定义
承载技能与性格、用于生产能量的基础单位；怪物的技能数量下限为 1、上限为 4。

# 组成
一只完整的怪物由以下内容构成：**性格 ×1、种族 ×1、技能 ×1~4**，并由技能的稀有度算出价格。

# 生成顺序

| 顺序  | 步骤   | 详细描述                                                                 |
| --- | ---- | -------------------------------------------------------------------- |
| 1   | 确定性格 | 按性格概率掷骰（白 50% / 蓝 20% / 负面 20% / 金 10%）；子代另见培育槽的继承规则                 |
| 2   | 确定种族 | 从五个种族中等概率随机；子代另见培育槽的继承规则                                             |
| 3   | 生成技能 | 先定技能数量 → 逐个掷稀有度（白 70% / 蓝 20% / 金 10%）→ 从技能池抽取，不可重复；单技能怪物不会抽到增幅。上限 4 |
| 4   | 计算价格 | 每个白技能 +10、蓝技能 +20、金技能 +30 金币                                         |

# 存放
怪物存放在怪物笼中，跨关卡保存，一局游戏结束后清空。

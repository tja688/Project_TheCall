# 定义
影响怪物能量值的机制，怪物初始心情为普通。

# 按天计算

每天开始，按此前已经完成的连续工作或休息天数决定当天基础心情；普通计算结果在当天保持。参加过当天任一轮结算算工作一天，加班不额外算一天；仅拖入又取回且未参加结算不算工作。连续工作两天，第三天才按疲倦计算；连续休息两天，第三天返回工作时仍享受热情。

性格与工具的显式覆盖次序见[已确认落地规格](../../../docs/specs/new-planning-playable-migration.md)。

# 档位
心情共 5 个档位，由低到高依次为 倦怠 → 疲倦 → 普通 → 热情 → 热爱。描述中提到的"提升一个档位"即沿此顺序向上移动一档，最高不超过热爱。

| 档位  | 能量值 | 触发条件                    |
| --- | --- | ----------------------- |
| 倦怠  | -2  | 怪物连续进入提取槽大于等于 4 天       |
| 疲倦  | -1  | 怪物连续进入提取槽达到 2-3 天       |
| 普通  | 0   | 初始即为普通；不满足其他档位条件时，重置为普通 |
| 热情  | +1  | 怪物连续未进入提取槽达到 2-3 天      |
| 热爱  | +2  | 怪物连续未进入提取槽大于等于 4 天      |

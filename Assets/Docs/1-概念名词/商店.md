# 定义
可以消耗金币提升玩家的区域



| 消费类型 | 详细介绍                                                                                      |
| ---- | ----------------------------------------------------------------------------------------- |
| 出售怪物 | 玩家可自由出售怪物笼中的怪物到商店以换取金币（单技能5金币，双技能10金币，三技能15金币）                                            |
| 购买怪物 | 出现4只可购买的怪物（怪物携带的技能数量根据概率来，单技能60%，双技能(两个技能均不为增幅功能类型)10%，双技能（一个技能为增幅功能类型，一个技能为其他任意功能类型）30%） |
| 购买工具 | 出现2件可供购买的工具                                                                               |
| 刷新   | 消费5金币，刷新所有商品，每使用一次价格翻倍，每个关卡开始时重置                                                          |

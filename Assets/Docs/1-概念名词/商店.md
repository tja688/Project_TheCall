# 定义
可以消耗金币提升玩家的区域。

| 消费类型 | 详细介绍                                                                            |
| ---- | ------------------------------------------------------------------------------- |
| 购买怪物 | 出现 4 只可购买的怪物。技能数量按概率生成：单技能 60%；双技能 10%（两个技能都不是增幅）；双技能 30%（一个技能是增幅，另一个是其他任意功能类型） |
| 购买工具 | 出现 2 件可供购买的工具                                                                   |
| 刷新   | 消费 5 金币，刷新所有商品；每使用一次，刷新费翻倍（5 → 10 → 20……），每关开始时重置                               |

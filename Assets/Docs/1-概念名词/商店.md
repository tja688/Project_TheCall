# 定义
可以消耗金币提升玩家的区域



| 消费类型 | 详细介绍                                           |
| ---- | ---------------------------------------------- |
| 出售怪物 | 玩家可自由出售怪物笼中的怪物到商店以换取金币（单技能5金币，双技能10金币，三技能15金币） |
| 购买怪物 | 出现4只可购买的怪物（怪物携带的技能数量根据概率来，单技能90%，双技能10%）       |
| 购买工具 | 出现2件可供购买的工具                                    |

# MONSTER BREEDING COMPANY MUSIC CONFIGURATION

## 配置说明

- 本文档仅覆盖当前已确认的 4 首循环音乐：主菜单、新手教程、关卡内、商店。
- 单日结算界面不播放 BGM，由结算相关音效承担反馈。
- 所有 BGM 均已在音频资产内完成循环点；Unity 侧只需在对应 `AudioSource` 勾选 `Loop`。
- 音乐切换由全局 `MusicManager` 统一管理。同一时刻仅允许 1 首 BGM 完整播放；交叉淡化期间允许旧曲与新曲短暂并发。
- 下方淡化时长为初始建议值，后续可按音乐实际听感调整。

## 音乐状态流

```text
主菜单
  └─ 点击开始游戏
      └─ 新手教程
          └─ 教程完成，正式进入第一天
              └─ 关卡内
                  └─ 当天完成，结算界面出现
                      └─ 静音
                          └─ 结算结束，商店界面打开
                              └─ 商店
                                  └─ 点击下一天，进入下一关
                                      └─ 关卡内
```

## 1. 主菜单音乐 / S_BGM_Menu Loop

### S_BGM_Menu Loop

**触发条件：** 游戏进入主菜单或标题界面。  
**触发来源：** 游戏流程 / 主菜单界面。  

**样本数量：** 1 首循环音乐。  
**播放模式：** 循环播放；在 Unity 的 `AudioSource` 勾选 `Loop`。  
**并发规则：** 正常状态下不与其他 BGM 并发；切入新手教程时，仅在交叉淡化期间与新手教程音乐短暂并发。  

**停止条件：** 玩家点击开始游戏，且即将进入新手教程时。  
**文件位置：** Sound\BGM\S_BGM_Menu Loop
**配置备注：** 点击开始游戏后，以约 `0.8 - 1.0 秒`淡出本曲，同时让新手教程音乐以相同时长淡入；

## 2. 新手教程音乐 / S_BGM_Tutorial Loop

### S_BGM_Tutorial Loop

**触发条件：** 玩家点击开始游戏后，进入新手教程。  
**触发来源：** 游戏流程 / 新手教程界面。  
**触发时机：** 新手教程界面正式出现时。  

**样本数量：** 1 首循环音乐。  
**播放模式：** 循环播放；在 Unity 的 `AudioSource` 勾选 `Loop`。  
**并发规则：** 正常状态下不与其他 BGM 并发；与主菜单音乐、关卡内音乐的交接期间允许短暂交叉淡化。  

**停止条件：** 教程完成，并正式进入第一天的关卡界面时。  
**文件位置：**  Sound\BGM\S_BGM_Tutorial Loop
**配置备注：** 从主菜单进入时淡入；教程完成时以约 `0.8 - 1.0 秒`淡出，同时让关卡内音乐淡入。若玩家跳过教程并直接开始游戏，则跳过本曲，直接从主菜单音乐交叉淡化到关卡内音乐。

## 3. 关卡内音乐 / S_BGM_Level Loop

### S_BGM_Level Loop

**触发条件：** 玩家完成教程后进入第一天，或在商店点击“下一天”后进入新的关卡。  
**触发来源：** 游戏流程 / 关卡界面。  
**触发时机：** 新一天的关卡界面正式出现时。  

**样本数量：** 1 首循环音乐。  
**播放模式：** 循环播放；在 Unity 的 `AudioSource` 勾选 `Loop`。  
**并发规则：** 覆盖关卡开始、操作、结算动画与工资结算阶段；不因单局时长变化或阶段切换而重播。仅与教程音乐或商店音乐交接时短暂并发。  

**停止条件：** 当天完成，单日结算界面完整出现时。  
**文件位置：** Sound\BGM\S_BGM_Level Loop
**配置备注：** 当玩家结束当天流程后，先让关卡内相关动画和音效播放；当结算界面正式出现时，以约 `0.5 - 0.8 秒`淡出并停止本曲。结算界面保持无 BGM。进入商店前不依赖固定等待时间，而以“商店界面正式打开”为切换事件。

---

## 4. 商店音乐 / S_BGM_Shop Loop

### S_BGM_Shop Loop

**触发条件：** 单日结算结束，玩家进入商店购买阶段。  
**触发来源：** 游戏流程 / 商店界面。  
**触发时机：** 商店界面正式打开且可交互时。  

**样本数量：** 1 首循环音乐。  
**播放模式：** 循环播放；在 Unity 的 `AudioSource` 勾选 `Loop`。  
**并发规则：** 正常状态下不与其他 BGM 并发；切入下一天时，仅在交叉淡化期间与关卡内音乐短暂并发。  

**停止条件：** 玩家点击“下一天”并确认离开商店，或本局游戏结束时。  
**文件位置：** Sound\BGM\ S_BGM_Shop Loop
**配置备注：** 商店界面打开时以约 `0.4 - 0.6 秒`淡入。本曲不需要等待结算界面的固定时长；只在商店正式出现后播放。玩家点击“下一天”后，以约 `0.5 - 0.8 秒`淡出，并在新一天的关卡界面出现时淡入关卡内音乐。

## 5. Unity 音频管线 / Unity Audio Pipeline

查了一下unity应该也有音频管线系统，建立管线后续调整整体音量会比较方便

### 5.1 Audio Mixer 结构

新建全局 `GameAudioMixer`，初始结构如下：

```text
Master
├── BGM
└── SFX
```

- `Music` 与 `SFX` 均输出至 `Master`。
- 当前 4 个 BGM 的 `AudioSource > Output` 均指向 `Music` Mixer Group。
  !!!注意：后续环境声、UI 或其他分类需要独立调音时，需要可在 `Master` 下继续增加 `Ambience`、`UI` 等 Group；本次不要求新增。



### 5.2 Mixer 参数

建议在 `GameAudioMixer` 中暴露以下参数：

| 参数名 | 对应 Group | 用途 |
| --- | --- | --- |
| `MasterVolume` | Master | 游戏总音量设置 |
| `MusicVolume` | Music | 音乐总音量设置、暂停时压低音乐音量 |
| `SFXVolume` | SFX | 音效总音量设置 |


**配置备注：** 
暂停、设置、科技等覆盖式面板默认不切换 BGM。若需要突出暂停状态，可临时压低 `MusicVolume`，关闭面板后恢复。但这个优先级相对比较低，可以等到咱们最后还有时间的话在进行调优啥的

# 结算遍序读触发当时的格子

结算遍序以 Midnight Rogues 的时间轴为准；商店、战斗外重排和一局进程仍看小丑牌与大巴扎。播放头沿当前排走，可倒放、再走一遍或提前触发，左右与相邻读这一刻的格子，在场怪物的格子不因别人被拿走而挪动；消灭要么效果当时立刻拿走，要么等到战斗结束回调之后。重触发是停留期间每个秒点的毒跳伤再结算一遍，来源再多也只再一遍；同一批按当前排和格子当场算完，先写的数后面读得到，排到稍后现实时刻的写入要等落下。

换位、技能再走的次数和单词条，Midnight Rogues 没有，用小丑牌的计分遍序补。换位等全部计分结束再按登记顺序交换，倒放和再走都算计分，避免播放头重复进入刚换过的格子。技能在秒点之外再走的次数于停留开始时加总，触发两次记再走 1 次；只加在产能量技能上的另计，两边相加。单词条指这只怪物身上只出现一个词条。战斗结束才拿走的消灭按登记顺序，同一时刻从左到右。

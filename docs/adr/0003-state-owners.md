# 对局与关卡分开持有状态，收支不另设主人

跨关状态放在对局：阶段、关卡序号、胜负、金币、科技点、已解锁科技、工具次序、技能槽、怪物笼及技能实例。当前关的应交能量、欠额、加班、本关能量、本关已付的商店刷新次数、提取槽和未生成的培育方案放在关卡，离开关卡即清空。技能、工具、科技、词条的静态定义和行为查找是内容目录，不存放本局改过的数。

流程、结算、培育、商店各自负责一类规则。能量、金币、科技点不另设规则主人，谁造成收支谁改状态。技能行为只交出意图，由结算规则统一执行。

玩家只在需要选择时发命令：开局留下哪一只、操作阶段的摆放与确认、解锁科技、商店的购买、刷新货架与离开。确认结算这一条命令跑完计分、换位、消灭和扣除；偿付成功则继续发工资并停在商店。离开商店后进入下一关开始或胜利。加班仍未补足欠额，则在扣除处游戏失败。一局只指走完七关。

# 对局与关卡分开持有状态，收支不另设主人

跨关保留的数据归对局持有，包括关卡进度、胜负、金币、科技点、已解锁科技、工具、基因槽和怪物笼。当前关的数据归关卡持有，包括关卡目标、当前能量、操作区域、商店刷新次数和本关培育状态；离开关卡后清理。

怪物、技能、性格、种族、工具和科技的静态定义归内容目录。本局产生的变更由对应领域规则处理。

流程、结算、培育、商店各自负责一类规则。能量、金币、科技点不另设规则主人，造成收支的规则负责修改对应状态。技能行为提交效果意图，由结算规则按当前版本策划执行。

本 ADR 只约束状态归属与规则边界。玩家操作、结算顺序、失败条件、培育继承和关卡推进均以 `Assets/Docs/` 的当前版本策划为准。

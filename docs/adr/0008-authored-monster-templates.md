# 怪物外观以完整成品模板为单位

独立随机头、嘴、手脚，再按技能叠加结构，无法稳定保留美术完成稿的比例与轮廓。采用 12 套人工固定的分层模板，变化限制在整套色卡与经过逐模板适配的头饰、背饰；相较整张烘焙图片，分层保留了性格眼型、眨眼、呼吸和饰品摆动。

怪物出生后持有固定的模板、色卡与饰品，技能不再改变身体结构。性格决定眼型，真实心情决定动作状态；完整外观由现有 `MonsterView` 快照交给所有画像入口。培育按用户确认的 80% 亲本完整模板、20% 其他成品模板执行，色卡沿用次亲本，饰品仅继承兼容组合，外观抽选不消耗玩法随机数。

此决定替代旧六体型、九结构槽和技能外挂的视觉策略，继续遵守 ADR 0003、0004、0006、0007 的状态归属、引擎隔离与结算边界。美术维护和验收入口见[成品模板系统](../presentation/monster-system.md)。

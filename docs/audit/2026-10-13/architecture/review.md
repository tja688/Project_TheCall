# 表现接缝整理与验收

本轮保留当前玩法规则和保存的 Main 场景，将美术修改入口从总控移入各界面。`TheCallPresentation` 从 1,181 行缩到 747 行，继续负责命令、界面流程与音乐。现有图鉴改动保留。

## 已落实的整理

| 接缝 | 改动 | 验证 |
| --- | --- | --- |
| 界面绘制 | 六个 `ScreenView.Render` 接管查询投影和控件；怪物画像与怪物笼共享绘制 | 当前 Main 场景、缺省按钮/标签、18 工具、30 怪物 |
| 新按钮 | `PresentationActionButton` 声明动作；原按钮和新按钮共用 `Perform` | 实际射线点击，自动寻找独立场景根总控，原按钮的 None/启用/停用切换 |
| 基因输入 | `HasPayload` 来自基因投影；指针来自所属操作界面 | 删除按钮与标签后的实际安装，安装拒绝，培育预约与原格退还 |
| 结算演出 | `SettlementPlayback` 接管规则交接；`ScoringShow` 消费 tape 并报告进展 | 真实播放的刷新、停用、取消、重启、重复播放与销毁 |
| 怪物笼滚动 | 内容高度依据有效卡片；缩小时收回旧滚动范围 | 30 张缓存卡片后只剩一只怪物，能立即显示和接受基因 |

隐藏的缓存卡片曾维持 1,778 像素的内容高度；只剩一只怪物时，内容仍滚到 1,420 像素，第一张卡片中心在屏幕 Y=2,276。`inventory-scroll-before.json` 保留了现场值。修复后实际安装通过，新 Editor 回归用例也覆盖这个过程。

## 验证结果

- Unity 6000.6.0f1，CLI 1.0.0-beta.13。复用既有 ready Editor。
- 最终 Editor 测试 511/511，通过，无跳过。
- 独立规则测试 416/416，通过，无跳过。
- seed 90 的七天正常、快进、跳过回放各完成 125 次玩家输入，并显示胜利界面。
- 三种模式每次操作后的完整规则状态、最终状态与生产记录逐字一致。SHA-256 在 `playback-parity.json`。
- 最后一次滚动和指针修复后，再跑一遍跳过模式的 125 次输入，逐步状态与此前三组比较。结果在 `final-replay-parity.json`。
- 空提取槽自然进入加班，再次不足后显示失败；原重启按钮返回新局。
- 播放中的重复刷新不会提前隐藏操作界面；返回标题和停用总控能退休旧回调与阻挡层。
- 原设置、手册、日志入口保持可用，浏览内容不改变对局。
- 验收期间未修改保存的 Main 场景；运行时检查没有新增错误或异常。

`ui-fixtures/` 中的工具、库存和基因检查使用局部资源注入，仅用于检验表现接入。七天回放使用原游戏的按钮与拖动入口，除固定随机种子外不注入资源。

# 新版策划落地对齐记录

> 2026-10-20 起，怪物拼接、骨架、部件目录和拼装工作区已从工程删除。下文若提到它们，只作当时记录。新系统从 `Assets/Notes/新怪物系统交接.md` 开始。


策划基线：`af170a044b09acfc0ab4e124974deb63c039123d`。两轮对齐已完成。用户最终确认Q17采用默认全来源加成，其余第二轮建议授权按讨论中的理解执行。完整开发与验收以[新版落地规格](../specs/new-planning-playable-migration.md)为准。

完整规格已发布为[GitHub issue #16：新版策划落地：完整七天玩法、Unity内容与界面交付](https://github.com/tja688/Project_TheCall/issues/16)，标记 `ready-for-agent`。issue正文包含整份规格，不依赖本地尚未提交的文档；主交付M0–M5与独立后续音频里程碑均已写明。

## 第一轮已确认

| 编号 | 决定 |
| --- | --- |
| D1 | 主交付覆盖全部新版玩法内容、七天整局、界面适配和结算解释。多复用现有资产与模板，在 Unity 引擎中真实构建完整内容并验收，交付不止规则代码。音频另设里程碑。 |
| D2 | 策划对上一版规则大体满意。保留现有结算主体，仅调整新版性格和效果需要改变的结算顺序，具体行为以确认后的场景为准。见 ADR 0007。 |
| D3 | 依赖只翻倍能量值的变化量，不翻倍基础产出。基础 5、加成 +3 的结果为 11。 |
| D4 | 每天开始根据此前已完成的工作或休息天数决定当天心情；当天参加过任一轮结算算工作一天，加班不额外算一天。仅拖入又取回、未参加结算不算工作。常规心情在当天保持；性格与工具的显式覆盖次序另行确认。 |
| D5 | 上关保留能量可以帮助本关达到超额门槛、取得科技点。 |
| D6 | 每只怪物每天第一次成功放入提取槽触发一次开工；换格、取回再放和加班不重复触发，性格改变也不重置当天次数。 |
| D7 | 技能效果造成的新增技能和增减默认持续当天，永久词条例外；性格造成的改造跨天保留。好学、好奇的改造常驻；移植胚胎、不稳定肉体、无穷肌肉获得的技能在关后清理。培育、购买、基因安装得到的技能常驻。 |
| D8 | 亲本保留。基因是一次性材料，只有实际加入子代或安装成功才消耗。 |
| D9 | 每种工具最多一件；每项科技每局解锁一次；已购买工具不再出现在货架。工具总持有量不设额外栏位上限。基因仓储把基因槽容量从 3 提升为 4，界面加号是其快捷入口。 |

第一轮尚未回答的负产能下限和百分比保留取整，已在第二轮Q19随其他建议一起接受：最终产能截到0，百分比保留向下取整。

## 第二轮已确认与授权

| 题号 | 最终决定 |
| --- | --- |
| Q10 | 保持开场怪物身份的普通执行顺序；换位即时处理，成功后插入目标主动技能各一次，再继续换位者；不动限制双方，交换尝试后使用者获得当天不动。位置条件按确认的快照和新事件边界判定。 |
| Q11 | 每技能轮到时锁定次数，已结束者不回访；增生A/B/C为1/2/4。每次怪物执行确定主动列表，新主动从下一执行生效，取得的新光环立即生效，新监听从后续事件生效。 |
| Q12 | 左右多目标逐只处理，每次死亡反应完整结束后继续；死亡撤光环，遗赠及存活提取槽监听器按位置和技能顺序响应。自爆后停剩余技能，缺目标按固定产能／实际数量处理。 |
| Q13 | 复读腺覆盖全部取得来源，独立实例仍受上限。安于现状裁至两项；已有怪物的随机裁切至少保留一个常驻实例，避免次日零技能。 |
| Q14 | 新实例从技能基础数值开始，不复制来源成长；好奇替换时移除原技能成长、保留怪物常驻增益。好学成功取得技能才更换性格，失败不补开工。 |
| Q15 | 达标确定培育组合，商店不出售预约亲本；次日清临时后取常驻技能。来源去重不足合并、超上限随机裁切；材料原位占用至实际使用，未使用安全退回。 |
| Q16 | 历史与性格 → 隔音棉 → 怪物严选 → 固定性格覆盖；隔音棉防工作下降，不能改固定档；普通以上含普通。 |
| Q17 | 用户明确覆盖原建议：未明说技能／性格等来源限定时，对所有符合目标范围的来源加成。保留本怪物、相邻怪物、全场等目标限定。 |
| Q18 | 相生组合无左右方向要求，每对相邻独立叠加；相克不凭空加效果。种族以图文及配色标识，复用原有组装造型。 |
| Q19 | 最终产能最低0，保留20%向下取整；操作按钮开始／加班结算，商店出口下一天／结束本局。 |

上述授权允许把已确认规则的必要推论写入最终spec。例如工具稀有度先抽档再抽条目、事件监听不追补当前批次、技能裁切保持至少一项常驻，均用于保持明确的概率、事件次数和一技能下限，不新增系统或扩大交付范围。

## 当前项目事实与落地约束

- 现有整局流程、拖放、培育、商店、科技、结算记录与动画可复用；新增性格、种族、心情尚未进入核心怪物状态。
- 运行内容表为 30 技能、3 工具、5 科技；新版策划为 34 技能、25 性格、18 工具、6 科技、5 种族及 5 档心情。
- 现有测试包含旧结算、科技发放、一亲本培育等断言；通过这些测试不能证明新版规则完成。
- 初次调查时旧 issue #1《落地最小可玩一局的规则与结算》仍开放且标为ready-for-agent；发布前实时核对发现它已关闭。新spec仍明确取代旧正文，避免AI引用冲突规则，无需再次关闭旧issue。
- 后续验收必须包含真实 Unity 场景、Prefab、内容资产映射和完整七天交互；规则测试是其中一部分。
- 遵守仓库 Unity CLI、现有分支、禁止手改场景 YAML、QFramework 状态归属等约定。

## 已证实的美术意图

主体、头、前肢和大部分配件采用白色填充与黑色描边。白色填充提供染色空间，黑线负责把轮廓收住。参考成图使用紫色主体与绿色四肢，并未要求主体全黑。设施中原有黑剪影只是旧占位表现。

眼睛、牙齿和嘴线独立覆盖。眼睛 PNG 大多数是一只眼，不是一对眼。它们的原生尺寸很小，适合 279×299 的画像，不适合无限放大。副头与附生半身仍是一只怪物，不产生额外结算实体。

心情与性格独立。初稿明确写明五档心情默认不替换性格眼型。心情可以改变轻微姿态、呼吸与活跃程度，性格眼型保持可识别。借面类机制实际改变性格时，再由新的性格选择眼型。

技能可以通过替换件或外挂件表达，但素材不要求每个效果制作一张整身图。成长类效果使用固定图表达，不按每一天新增角节或补丁。多手、多头不会额外触发一次技能。

## 结构模板与挂点

下面六类对应 `Assets/Editor/MonsterArtIntegration.cs` 的 `Plans()` 默认值，并非美术已经批准的六个种族。实际使用的参数保存在 `Assets/Resources/MonsterArtCatalog.asset`，Inspector 中的人工调参可以与代码默认值不同。体型与现有五种族分别记录。一个种族可以使用多种体型，体型也不自动赋予技能。`head` 由头部基因选择圆头 `936`、扁头 `951` 或星头 `990`，星头属于头部差分，没有独立的星形身体模板。

模板坐标以画像底部中点为原点，向上为正，单位为画像局部像素。`position` 是组件中心，`size` 是允许的最大框，实际图片保持有效包围盒比例。最终绘制进入 279×299 外框，并用目录中的 `viewportFill` 留出边缘空间。不要把坐标误当作画像中心原点。

### 遮挡与尺度

PSB 的贪食范例证实以下顺序：后脚和后手在最底层，随后是完整口腔、内舌和牙；胖体盖在口腔之上，最后画嘴外部件和前肢。运行时可按以下顺序安排。

| 层级 | 内容 | 原因 |
| --- | --- | --- |
| 0 | 后翼、后尾、后角、副头颈根 | 主体遮住根部 |
| 1 | 后手、后脚 | 和前肢区分前后 |
| 2 | 口腔底、内舌、牙 | 从胖体开口中露出 |
| 3 | 身体、弯颈、头 | 把根部和口腔边缘收住 |
| 4 | 身体花纹、缝线、腮红 | 不改变结构轮廓 |
| 5 | 眼、闭嘴线、外挂腹口 | 脸区保持可读 |
| 6 | 前手、前脚、外舌、顶角 | 保留前后遮挡 |

后肢使用同一套造型，颜色明度约为前肢的 70%～82%。前肢根部向主体埋入 10%～20%，不要刚好相切。头与颈、颈与躯干也需要交叠，但不能靠无限拉长图片填缝。

星头的中央是凹谷，中央 alpha 实部比图片最高点低约 21%。因此 `MonsterComposition` 在表中 crown 基准上额外下移 14 像素；其他头形和头身一体模板下移 3 像素，再分别放置角或脑部。角根必须进入真正的头部实色区域，不能以图片外框最高点判断连接。

镜像只改变左右朝向，不改变眼型家族。`MonsterComposition` 的 `faceWidth` 是眼部布局基准宽度，不是整张头的宽度。当前每只眼框宽为该值的 38%，眼中心各偏移该值的 27%。换图时同时确认眼睛有效宽高，不能只根据文件外框判断。副头沿用同一家族眼型。正视双眼与侧视单眼若作为后续模板差分加入，必须保持同一只怪物的选择稳定。

### 开嘴与闭嘴兼容

`fat_*_open*` 已经在主体轮廓中切出口型，不能再贴一张完整闭嘴覆盖。完整口腔 `oral_484` 放在开口后方，牙件沿上口缘摆放，`oral_506` 位于下部。小胖的口腔框为 `Rect(-33,124,103,52)`，大胖为 `Rect(-28,131,98,49)`。口腔向左延伸，填住开口实部之间的空区，不留下背景色裂缝。

`oral_484` 是无描边的纯色椭圆，当前唯一允许水平拉伸的图片。它直接使用口腔框大小。身体、头、肢体、眼、牙、舌和其他配件全部保持有效包围盒的原始宽高比例。口腔、牙和舌有独立色彩，保证深色身体仍有可读的口内结构。

闭合体使用 `mouth_538`、`mouth_835`、`mouth_837`、`mouth_848` 或 `mark_844`。外舌 `407`、`482` 从已有嘴缝或开口伸出，不能悬在无嘴腹部。已经自带整排牙的 `835`、`837` 不再叠加 `718`、`719`、`725`。

## 性格与心情的映射边界

初稿五类性格眼型是焦虑、冷漠、狂躁、怠惰、渴爱。实际内容目录有 25 个机制性格，二者没有原稿规定的对应表。因此，当前映射是美术解释，不更改性格名、效果或继承概率。

| 眼型家族 | 语义映射建议 | 可用 PNG |
| --- | --- | --- |
| 焦虑 | 自律、依赖、好学、好奇、随心所欲 | `eye_768_焦虑`、`eye_857_焦虑2` |
| 冷漠 | 稳定、孤僻、独立、稳重、安于现状 | `eye_854_冷漠_疲惫`、`eye_861_冷漠`、`eye_863_冷漠` |
| 狂躁 | 自私、贪财、急躁、仇恨血脉 | `eye_909_狂躁`、`eye_912_狂躁2` |
| 怠惰 | 摸鱼派、厌恶工作、厌世、迷恋死亡 | `eye_713_怠惰` |
| 渴爱 | 重视血脉、合群、恋爱脑、乐天派、热爱工作、乐于助人、上进心 | `eye_867_渴爱`、`eye_872_渴爱2` |

五档心情只影响当日状态表现。倦怠与疲倦可减小呼吸、降低姿态；热情与热爱可加快轻微呼吸并增加有限的弹性。不要把怠惰眼换成狂躁眼表示心情变好。玩家选中、拖动、工作弹动与基础呼吸分别控制，结算快进和跳过仍使用原有生命周期。

初稿 25 项技能化名称实际对应原性格机制。例如缄口对应稳定，自缚对应孤僻，怒放对应乐天派，垂肢对应摸鱼派。原稿明确说这 25 项不能直接占用现有 34 技能池的槽位。原稿中的棉团、面具、袖套、闭环尾、残端和完整断腕当前均未独立交付。现有素材复用必须在交接中明确，不能宣称这些专属图已接入。

### 挂点冲突

基础结构始终保留一块主脸区、至少一个支撑地面的肢体组。当前脑部优先于遗传顶角，肥大手优先于短小手，暗色肢体优先占主臂和脚的素材槽。增生手臂使用下层独立挂点。缝合嘴压制长舌和分叉舌，保证闭嘴语义完整。

技能缝线、星纹和斑纹优先使用主要花纹槽，顺序为缝线、星纹、斑纹。不同的遗传花纹使用 55% 大小的次要槽；若没有不同的遗传花纹，再把第二种技能花纹放入次要槽。两槽以外的花纹不继续累加。

胖体的副头中心为 `(-80,226)`，最大框 67×53。副颈在主体之前绘制，根部由主体遮挡。副头和副脸先画，主脸最后画，保留主眼区。双端宽肩自身已有两个头，不再叠第三头。空洞眼饰放在主右眼外侧偏下，不能直接盖住主性格眼。

同一技能的重复实例不必复制同尺寸附件。可以改变有限的数量、细小标记或对称方式，避免一只怪物因 4 个技能变成不可读的附件团。绘制选择使用固定顺序和固定上限，技能获得、重组和安装后重新投影；没有变化时不得重新抽样。

## 后续替换与调参

原图保留在原目录，运行时从目录引用。`Assets/Resources/MonsterArtCatalog.asset` 的 Inspector 是当前调参入口。`bodies` 保存六种模板的组件位置、最大框、角度、镜像和挂点；`palettes` 保存身体、肢体与强调色；`viewportFill` 控制画像中的整体占比；`idleMotion` 控制呼吸和小幅摆动的强度。运行时目录 revision 变化会触发现有画像重绘。

菜单 **TheCall/Monster/更新部件目录与图集** 调用 `MonsterArtIntegration.Apply()`，重新扫描组件和打包图集，同时保留已保存的模板与配色调参。开发调用 `MonsterArtIntegration.Apply(true)` 将 `bodies` 和 `palettes` 恢复为脚本默认值；这个调用不重置 `viewportFill` 与 `idleMotion`。恢复默认值会覆盖上述两组人工调参，应只在明确需要恢复时调用。

替换件保留语义类别、根部方向、原始宽高比例和层级约定。新图超出原尺寸时，同时校准挂点、脸区和最终轮廓包围盒，不能只改 Sprite 引用。

调参先固定同一只怪物和同一心情，比较开局、商店、宿舍、提取槽、培育槽、胜负、拖动虚影与结算镜像。所有入口必须显示同一套遗传结构。再单独切换心情，检查眼型稳定。最后安装或移除技能，检查主脸不跳位、附件不浮空、技能标记不遮脸。

重画专属件时，优先补齐当前复用差距最大的长鼻、闭环尾、钩尾、面具、袖套、棉团、残端、断腕和骨饰。素材齐备后只替换对应挂点的造型；玩法仍读取内容目录，不能从外观是否显示某件判断技能是否存在。

素材核验的重跑命令如下。脚本写入的只有审计 JSON。

```powershell
python scripts/audit-monster-art.py
python scripts/audit-monster-art.py --check
```

首次命令生成新的原图清单。第二条比较 SHA-256、尺寸、透明范围和文件集合。美术有意更换原文件时，审阅来源差异后再重新生成清单。这个检查证明源素材保持一致，完整场景观感和交互仍须通过实际 Unity 画像验收。

# 完整怪物美术规则

2026-10-21 临时修补：所有正式立绘使用纯色填充，取消渐变及白色保护区，解决眼睛、嘴部周围的大块发白。原稿不改写。

以 `Assets/示意图/怪物实例.jpg` 为造型原稿。每个怪物是一张完整立绘，保留老师绘制的形体、眼睛、针脚、口腔和四肢。游戏运行时不添加、替换或拼接任何部位。

基础池使用原稿中的六个白色造型。培育池使用原稿中的六个复杂彩色造型。两池都允许苔绿、暮紫、莓红、奶油、雾青与月蓝六种纯色。颜色在出生时固定，后续技能、性格、心情与继承状态只通过文字和状态界面表达。

纯色在导入时烘焙。临时修补取消白色保护范围，眼睛、牙齿、嘴部与身体使用同一个填充色，保留黑线和透明度。边缘使用真实透明度，去掉灰底、四肢空隙和灰色光边。

所有动作作用于整张图片，只保留轻微呼吸、拖动倾斜和既有结算反馈。不得恢复眨眼图层、器官摇摆或亲本部件混合。工具与替换方法见[完整怪物立绘](monster-system.md)。
